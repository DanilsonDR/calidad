# Prompts reutilizables para auditorías internas de calidad

## 1. Preparación inicial

```text
Actúa como auditor interno de calidad. Revisa los documentos entregados para esta auditoría y prepara un mapa de focos por riesgo.

No inventes datos. Usa solo los documentos entregados. Marca como `por verificar` lo que no esté soportado.

Entrega:
- alcance y criterios identificados;
- procesos/subprocesos incluidos;
- riesgos principales;
- acciones abiertas o pendientes;
- indicadores críticos;
- PQRSF o salidas no conformes a revisar;
- preguntas clave por responsable;
- evidencia mínima a solicitar;
- muestra recomendada.
```

## 2. Revisión de informe anterior

```text
Revisa el informe de auditoría anterior y extrae únicamente información útil para preparar la nueva auditoría.

Entrega:
1. fortalezas que conviene verificar si se mantienen;
2. aspectos por mejorar anteriores y su estado;
3. no conformidades o acciones correctivas anteriores;
4. recomendaciones que deben tener seguimiento;
5. señales de recurrencia;
6. riesgos que no deben pasarse por alto;
7. posibles preguntas para confirmar eficacia.
```

## 3. Análisis de acciones correctivas

```text
Analiza estas acciones correctivas/preventivas/de mejora.

No te quedes en si la actividad fue ejecutada. Evalúa si existe evidencia de eficacia.

Entrega una tabla con:
- acción;
- causa que busca controlar;
- evidencia de implementación;
- evidencia de eficacia esperada;
- pregunta de auditoría;
- riesgo si no se demuestra eficacia;
- posible conclusión.
```

## 4. Preparar entrevista por responsable

```text
Con base en el rol de este involucrado y los documentos entregados, prepara una guía de entrevista sencilla.

No hagas preguntas rebuscadas. Las preguntas deben ayudar a entender cómo opera el proceso y dónde queda la evidencia.

Entrega:
- objetivo de la entrevista;
- 8 a 12 preguntas sencillas;
- evidencia a pedir;
- señales de alerta;
- posibles seguimientos si la respuesta es incompleta.
```

## 5. Revisión de PQRSF, quejas y derechos de petición

```text
Analiza esta muestra de PQRSF, quejas, reclamos, derechos de petición o salidas no conformes.

Entrega:
- temas recurrentes;
- etapa del proceso donde se originan;
- causa probable soportada;
- si hay recurrencia;
- si existe acción tomada;
- si la acción parece eficaz;
- riesgos asociados;
- mejora concreta que no genere carga innecesaria.
```

## 6. Redacción de hallazgo

```text
Con la siguiente evidencia, ayúdame a redactar el resultado de auditoría.

Clasifica si corresponde a fortaleza, conformidad, aspecto por mejorar, observación o no conformidad. No fuerces una no conformidad si no hay criterio incumplido.

Estructura:
- criterio;
- condición encontrada;
- evidencia objetiva;
- análisis del riesgo o impacto;
- redacción sugerida;
- recomendación si aplica.
```

## 7. Control de calidad del informe

```text
Revisa este borrador de informe de auditoría como auditor líder.

Busca:
- afirmaciones sin evidencia;
- hallazgos débiles;
- recomendaciones genéricas;
- redacción que pueda sonar acusatoria;
- conclusiones que no se desprenden de la evidencia;
- oportunidades de mejora que no agregan valor;
- repetición innecesaria;
- falta de trazabilidad entre criterio, evidencia y conclusión.

Entrega correcciones puntuales y una versión mejorada lista para pegar.
```

## 8. Cierre ejecutivo

```text
Resume los resultados de la auditoría para reunión de cierre.

Debe sonar institucional, claro y equilibrado.

Incluye:
- alcance revisado;
- fortalezas principales;
- riesgos o puntos de atención;
- acciones a seguir;
- recomendaciones de valor;
- mensaje final de mejora continua.
```
