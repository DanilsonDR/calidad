# Paquete de Skill — Auditoría Interna de Calidad

[![Powered by RustChain](https://img.shields.io/badge/Powered%20by-RustChain-orange)](https://rustchain.org)

## Propósito

Este paquete ayuda al equipo auditor a usar IA de forma ordenada para preparar, ejecutar y documentar auditorías internas de calidad sin perder criterio profesional ni generar trabajo innecesario para los procesos auditados.

Este paquete se diseñó a partir del enfoque usado en auditorías internas de calidad de Combarranquilla: revisión documental, entrevistas, muestreo, seguimiento a acciones, gestión de riesgos y oportunidades, análisis de indicadores, PHVA y elaboración de informe. También incorpora aprendizajes observados en el proceso de Subsidios: la importancia de revisar acciones abiertas, recurrencia de salidas no conformes/PQRSF, control de cambios en sistemas, evidencias de eficacia y mejoras que realmente aporten valor.

## Cómo usarlo

1. Crear una carpeta por auditoría con el plan, informe anterior, acciones abiertas, caracterización, procedimientos, matriz de riesgos, matriz de oportunidades, indicadores, PQRSF y evidencias disponibles.
2. Abrir `SKILL.md` y copiar el prompt maestro en la herramienta de IA aprobada.
3. Usar los prompts de `PROMPTS_AUDITORIA.md` según la fase: preparación, análisis documental, entrevista, hallazgos o informe.
4. Validar todo contra evidencias reales antes de pasarlo al informe institucional.
5. No cargar información sensible, bases completas de usuarios o datos personales si la herramienta usada no está autorizada institucionalmente.

## Archivos incluidos

- `SKILL.md`: modo maestro para actuar como auditor interno de calidad.
- `PROMPTS_AUDITORIA.md`: prompts listos para copiar y pegar.
- `CHECKLIST_ISO9001.md`: preguntas guía por enfoque ISO 9001/PHVA.
- `GUIA_ANALISIS_DOCUMENTAL.md`: método para revisar documentos sin perderse.
- `GUIA_ENTREVISTAS.md`: preguntas sencillas y útiles para entrevistas.
- `MATRICES_Y_PLANTILLAS.md`: tablas base para análisis, muestra, hallazgos y evidencias.
- `GUIA_HALLAZGOS_E_INFORME.md`: cómo formular hallazgos, recomendaciones y conclusiones.
- `USO_SEGURO_IA.md`: reglas de confidencialidad, seguridad y límites del uso de IA.

## Regla principal

La IA apoya el análisis, pero el juicio auditor, la evidencia y el criterio institucional mandan.
